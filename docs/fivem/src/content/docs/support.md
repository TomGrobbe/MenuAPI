title: "Troubleshooting & Support"
---

:::note
Please note that MenuAPI is not a plug and play resource, and support for building menus for you is not provided. If you have a question that is not answered on the forum topic or on these docs, feel free to ask in the Discord server. Community members may be able to help, though a reply cannot be guaranteed.
:::

## Found a bug?
Check whether it has already been reported, either on the forums or on the GitHub issues page.

### It's not reported yet?
Please report it, and make it a clear report so it can be understood and reproduced. The more information you provide, the easier it is to look into and fix. Reports without enough detail are much harder to act on, so a little extra effort here goes a long way.

## You need help with creating a menu.
Please read the note above.

## You need help installing this resource.
### Are you a resource developer?
MenuAPI is not a plug and play resource. It is called an API for a reason, and it is meant to be implemented into your own resource, similar to the C# NativeUI API.

### You're a server owner?
Please ask your server developer for help. This is **NOT** a resource to install yourself. It is one to be implemented into other C# projects.

## Anything else?
Please check the docs and the GitHub issues page, since your question may already be addressed there. If you cannot find it, feel free to ask for help on the forum topic or in the Discord server (https://vespura.com/discord).
