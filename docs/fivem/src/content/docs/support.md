title: "Troubleshooting & Support"
---

:::note
MenuAPI is not a plug and play resource, and nobody will build your menus for you. If these docs and the forum topic do not answer your question, ask in the Discord server. Community members may help, but a reply is not guaranteed.
:::

## Found a bug?
Check whether it is already reported on the forums or on the GitHub issues page.

### It's not reported yet?
Report it with enough detail for someone else to understand and reproduce it.

## You need help with creating a menu.
See the note above.

## You need help installing this resource.
### Are you a resource developer?
MenuAPI is an API, not a plug and play resource. You build it into your own resource, like the C# NativeUI API.

### You're a server owner?
Ask your server developer. This is **NOT** a resource you install yourself. It is used inside other C# projects.

## Anything else?
Check the docs and the GitHub issues page first. If your question is not answered there, ask on the forum topic or in the Discord server (https://vespura.com/discord).
