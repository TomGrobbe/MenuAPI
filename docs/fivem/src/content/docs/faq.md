### Read this before asking for support

----

#### **Q:** Does this work with this \[enter name here\] \(RP\) Framework?

> **A:** It is a standalone C# API, so it does not depend on any framework. If your framework supports C# resources, it should work.

----

#### **Q:** HELP ME

> **A:** Read the [Troubleshooting & Support](../support/) page.

----

#### **Q:** Where's the LUA or JS version

> **A:** It is C# only. A wrapper may come later.

----

#### **Q:** How do I build a menu?

> **A:** See the [**API Reference**](../reference/).

----

#### **Q:** Do I need to draw menu's manually?

> **A:** No. Create a menu and add it with `MenuController.AddMenu(menu);` or `MenuController.AddSubmenu(parentMenu, menu);`.
